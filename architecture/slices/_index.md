## Aggregated lessons (from recent slices' "Lessons for next slice")

- **Execute a newly-authored content matcher against the REAL corpus's adversarial shapes — negation words AND noun-prone verbs — at authoring time** (slice-095) — the corpus literally contains the tokens a naive heuristic breaks on: legit routed lines carry `never`/`raw`/`don't` (`…via \`vault_edit append\` … never a raw \`Write\`/\`Edit\``), so a negation word-list false-VIOLATIONs them; the real fix is structural (route token must sit in a backtick code-span or `<!-- route: -->` marker + a TIGHT 2-word negation look-back). Unit fixtures share the matcher author's blind spot; the code-Critic is a required SECOND APED-1 author. Extends regex-APED-1/BC-PROJ-13 with the negation/noun-prone real-corpus-shape axis.
- **A "minor" correctness fix to a parser/audit can SURFACE latent state the buggy version masked** (slice-095) — the m1 CommonMark fence tracker un-hid triage:179 (a real project-open write hidden behind triage's malformed nested fence), reversing a build-time decision + cascading into a guarded-opener edit + an 11→12/21→22 count reconciliation across 4 files + 2 installed syncs. Budget for "what does correctness REVEAL", not only "what does it fix".
- **A lexical/static audit's honest contract is "fail-closed for RECOGNIZED inputs" + a pinned documented residual** (slice-095) — chasing completeness into noun/verb ambiguity (`note`/`record`/`set`; `register` ⊂ `risk-register.md`) buys false positives, not safety. Name the residual in code + a test so it stays visible, not silently assumed closed.
- **3-Critic stack complementarity held N+1 on a vault-infra slice (do NOT collapse)** (slice-095) — design+meta Critics ratified the matcher's INTENT (honest-scope, corpus enumeration, closed allowlist — all VALIDATED); the code-Critic EXECUTING adversarial inputs found three fail-OPEN holes (route-token false-CLEAN, narrow lexicon, pair-not-count pin) the design level structurally can't reach. The slice that built the vault-write safe channel dogfooded `vault_edit append` in its own /reflect lessons append.
- **Capability-without-flip de-risks an irreversible initiative** (slice-093) — ship the resolution chain + write-safety primitive + install config + classification map while the default STAYS `architecture/`; the scary, irreversible parts (physical move, history fork, prose rewrite) sit behind the seam for the NEXT slice. The no-flip invariant is a hard testable safety contract: every existing tool/test/skill behaves identically (full suite 1316 PASS).
- **The worktree-at-`/slice` model silently drops the R-20 `diagnose-out/`+`graphify-out/` seed** (slice-093) — `/build-slice`'s codified `cp -r` seed never runs when the worktree is created at `/slice` time. slice-094 must move the seed to `/slice` time (or factor a shared worktree-create helper invoked by BOTH `/slice` and `/build-slice`). R-20's slice-074 retirement was scoped to the create-at-`/build-slice` model only — Status stays `retired`, scope-clarified, not reopened.
- **The cp1252 class is now SELF-APPLYING, N≥8 across THREE mechanisms** (slice-093) — stdout (UTF8-STDOUT-1), subprocess-capture (BC-PROJ-15/BC-GLOBAL-5), and now **bare-`print`-to-stderr-at-import** (code-Critic M1, RSAD-1: the slice shipping vault infra nearly shipped its own cp1252 crash).
