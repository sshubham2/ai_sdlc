## Intent

This structurally retires the N=4 cumulative gitignored-vault-vs-worktree conflict class (every BRANCH-2 slice since slice-066 has paid a `cp -r architecture/` DEVIATION tax to seed the worktree with vault state) AND enables cross-machine parallel slice development by making the vault (risk-register, slice archive, ADRs, methodology-changelog, build-checks, lessons-learned, candidate queue) visible across machines via `git pull`.
