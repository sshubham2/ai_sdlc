## Confirmed findings

First-Critic findings the meta-Critic agrees with (VALID + correct severity):

- **B1: Test-breakage scope understated → ~20 tripwire trips → "1 slice" unsound** — CONFIRMED. Reproduced exactly: `AI_SDLC_VAULT_ROOT=<seeded-ext> pytest tests/methodology/` → **74 failed / 1351 passed**; `tests/skills/` → **7 failed / 106 passed**; baseline (no env) → **1425 passed / 0 failed**; the first Critic's pure-in-process subset → **30 failed / 76 passed**. Mechanism confirmed at `supersede_audit.py:173` and 30+ sibling `repo_root / VAULT_ROOT / ...` sites (`Grep` for `/ VAULT_ROOT`): an absolute `VAULT_ROOT` discards the caller's `repo_root` per pathlib. Severity Blocker is appropriate — even the most charitable subset (38 fixture-discard breakers, see M-add-4) exceeds the ~20 tripwire, so the one-slice path is empirically refuted.
- **B2: AC3 RETIRE signal-indistinguishable from UNKNOWN → routes to SOAD-1** — CONFIRMED at every cited line. `parallel_conflict_resolver.py:331-343` returns `action="STOP", conflict_class=ConflictClass.UNKNOWN`; CLI `:2393-2394` maps `UNKNOWN → return 1`; `skills/commit-slice/SKILL.md:198` routes `exit 1 (UNKNOWN)` to "fall through to the SOAD-1 3-option block." The only discriminator is the `reason` substring. `tests/methodology/test_slice_098_vault_routing.py:214` pins only `res.action == "STOP" and "external" in res.reason.lower()` — it asserts no distinct action and no distinct exit code, so the existing pin passes while AC3's "distinct PCR-RETIRE signal" remains unmet. ADR-100's "No resolver change" claim is genuinely false. Severity Blocker is appropriate on AC-satisfiability grounds (AC3 cannot pass as designed without the resolver change), even though the runtime fall-through is a safe-degraded manual stop rather than silent corruption — see Notes.
- **B3: Self-ref bootstrap break — `/reflect` archive `mv` is a literal in-tree path** — CONFIRMED. `skills/reflect/SKILL.md:320` is the literal `mv architecture/slices/slice-NNN-<name>/ architecture/slices/archive/`; post-flip `architecture/` is gitignored / `git rm --cached`'d so the source folder isn't the canonical vault. `tools/vault_flip_readiness_audit.py:488-507` (`_iter_scan_files`) globs only `tools/*.py` + `skills/**/*.py` + `tests/**/*.py` — it does NOT scan `SKILL.md` prose, so this break is invisible to AC2's readiness gate. The timing trap is real: slice-111 (the deferred prose fix) runs `/reflect` AFTER slice-110's own `/reflect` archive step. Severity Blocker is appropriate. (But the defect class is broader than `/reflect` alone — see M-add-1/M-add-2.)
- **M1: Rollback ordering + untracked-artifact recovery + EOL wording** — CONFIRMED. The EOL sub-claim is empirically verified: `.gitattributes` pins `eol=lf` ONLY on `architecture/slice-queue.md` under the vault tree; on-disk byte counts show `slice-queue.md` = LF-only (99/0) but `shippability.md` (0 LF / 124 CRLF), `risk-register.md` (0/622), `triage.md` (0/58) are all CRLF. The design's "byte-faithful LF-preserving" framing is wrong for the 1032-file bulk — a faithful move preserves CRLF, not LF. Severity Major is appropriate.
- **M2: AC2 readiness-gate cleanliness gives false flip-safety** — CONFIRMED. `vault_flip_readiness_audit.py:601-605` returns 2 only on `needs_human` or `--strict+drift`; live run exits **0** with `counts = {must-rewrite-before-flip: 0, needs-human-classification: 0, test-update-at-flip: 166, test-collection-pathspec: 49}`. The gate is green while 166+49 occurrences AND 81 actual test failures remain. Severity Major is appropriate; demoting the audit to necessary-not-sufficient and binding AC2 to a green full-suite-under-flip is the right fix.

## Missed findings

Concerns the first Critic didn't flag but the meta-Critic surfaces from independent re-review:

- **M-add-1 [Blocker] Self-ref bootstrap break is broader than `/reflect` — ALL literal-path per-slice-folder writes break post-flip.** (Newman, *Building Microservices* — seam-incompleteness; Wiegers — incomplete spec for the bootstrap state.) The design.md §self-ref-bootstrap claims "post-flip /validate+/reflect write directly external via VAULT_ROOT; no per-worktree architecture/ post-flip." This is only HALF true. The shared-aggregate files (`risk-register.md`, `lessons-learned.md`, `_index.md`, `shippability.md`, `build-checks.md`) ARE flip-safe because they route through `vault_edit --file <name>` (VAULT_ROOT-relative — confirmed at `skills/reflect/SKILL.md:56,145,266,321`). But the per-slice-FOLDER artifacts are NOT vault_edit-routed: `skills/reflect/SKILL.md:94` ("Write `architecture/slices/slice-NNN-<name>/reflection.md`"), `skills/validate-slice/SKILL.md:83` ("Write `architecture/slices/.../validation.md`"), `skills/drift-check/SKILL.md:109` ("Write `architecture/drift-log.md`"), and `skills/slice/SKILL.md:267-268` (scaffold Write to `<wt_path>/architecture/slices/...`) are all literal `Write`-tool targets at in-tree paths. Post-flip these resolve to the gitignored in-tree `architecture/` — NOT the external canonical store. The design's bootstrap resolution conflates the two write classes. **Proposed fix**: the prep slice must convert the per-slice-folder write convention to VAULT_ROOT-routed (or vault_edit-routed) writes for the whole slice-folder lifecycle (`/slice`, `/design-slice`, `/critique`, `/validate-slice`, `/reflect`, `/drift-check`), not just the `/reflect` `mv`. This is the genuine self-ref Blocker; B3 caught one symptom of it.

- **M-add-2 [Major] `/archive` carries the identical literal `mv architecture/...` that B3 flags in `/reflect`, but the Builder's prep-slice disposition names only `/reflect` + `/commit-slice`.** (Sommerville — change-impact completeness.) `skills/archive/SKILL.md:51` is `mv architecture/slices/slice-NNN-* architecture/slices/archive/` — the same break as `skills/reflect/SKILL.md:320`. `/archive` is the standalone sweep invoked when auto-archive is deferred, so it is a live (non-legacy) break. The Builder's draft prep-slice scope ("fixes /reflect + /commit-slice prose + extends readiness audit to scan .md") would MISS `/archive:51` unless explicitly enumerated. **Proposed fix**: add `skills/archive/SKILL.md:51` to the prep-slice prose-fix set; the readiness-audit `.md`-scan extension (already proposed in B3) will then catch it as a regression guard.

- **M-add-3 [Minor] `/build-slice:88` `git add architecture/...` and the `graphify vault architecture` target break post-flip; neither is in the Builder's prep scope.** (Newman — operational-tooling seam.) `skills/build-slice/SKILL.md:88` (`git add architecture/slices/... architecture/slice-queue.md`) stages an in-tree path that post-flip is gitignored/untracked — though it sits inside the BRANCH-3 *legacy-only* dirty-default path (point 4), so it is a latent rather than always-fired break (Minor, not Major). Separately, `$PY -m graphify vault architecture` is hardcoded in 6 skills incl. the in-loop `/design-slice:62` — post-flip it would build the graph from an empty/gitignored in-tree `architecture/`, silently producing a stale/empty vault graph (`graphify-out/` is gitignored — a derived-artifact interaction the first Critic did not mention). **Proposed fix**: enumerate `/build-slice:88` and the `graphify vault architecture` target (→ `graphify vault <external-root>` or VAULT_ROOT-derived) in the prep slice or the slice-111 prose rewrite; at minimum log them so they aren't silently missed.

- **M-add-4 [Minor / calibration] B1's 74 is correct but its COMPOSITION is unanalyzed, and the composition matters for the re-scope shape.** (Hendrickson — defect-classification rigor.) I categorized the 74 methodology failures: **38 are `repo_root=tmp` fixture-discard artifacts** (drift_check ×14, cross_spec ×7, supersede ×4, build_checks ×4, etc. — the audit reads the real external vault instead of the tmp fixture, pure test-repoint), and **36 are deliberate-RETIRE behavior-change tests** (stranded_slice ×8, pcr_1 ×8, pcr_2a/2b ×11, parallel_conflict_resolution_log ×4, etc. — these pin the PRE-flip in-tree behavior of code paths that, post-flip, CORRECTLY RETIRE per `vault_is_external()` / ADR-089; production is already correct, the tests pin stale behavior). This refinement does NOT change B1's verdict (both buckets independently exceed the ~20 tripwire, and both must be fixed for AC2's green suite), but it materially informs the prep-first re-scope: the prep slice's "repoint location-agnostic" work is straightforward for the 38, but the 36 RETIRE tests need REWRITING to assert the new RETIRE contract — that is design work, not a mechanical repoint, and the Builder's prep-slice estimate should account for it.
