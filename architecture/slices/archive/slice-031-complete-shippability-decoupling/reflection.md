## Lessons for next slice
- **Methodology-tooling slices: the audit's OWN parse rules are a blind spot.** A brief field-line annotation silently disabled TF-1 (R-7); a letter-suffixed folder broke BRANCH-1 (R-6). Design-stage Critics cannot see these. Mitigation: at /build-slice prerequisite AND pre-finish, run every gate on the *actual artifact* (not just unit fixtures) and read its output — "not enabled"/"usage-error" on a slice that should engage the gate is a silent-bypass signal.
- **AST-classification / parsing audits need a real-corpus smoke gate at ~50%.** Design-stage reasoning cannot enumerate the false-positive surface (synthetic test trees, unrelated home reads, const-aliased roots). Budget the smoke gate as the empirical oracle — slice-030A's lesson is now N+2.
- **Split convergence held end-to-end.** v1 BLOCKED → v2 NEEDS-FIXES → CLEAN → build converged in ONE build (3 smoke-driven implementation corrections, zero scope/design change, zero relocation). Prefer split over patch when the flaw is two features — confirmed a 2nd time after slice-030.
- **When canonical id ≠ split-label, record the alias up front.** The folder/branch rename churn (R-6) would have been avoided by deciding "numeric folder, prose label" at /slice and writing the milestone identity-note then. Next split slice (030C) must use a numeric folder from the start.
