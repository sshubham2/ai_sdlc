## Lessons for next slice

- **`audit-tools-default-utf8-stdout` is structurally overdue** — N=6 cumulative cp1252 recurrence; defer cost is paid at every /build-slice + /validate-slice + /reflect that touches a tool with non-ASCII stdout. Cheap SMALL slice; structural foreshadowing-decline says don't bundle into another themed slice — ship it focused.
- **Codification slices should self-apply their codified discipline at /build-slice prerequisite-check** — slice-022 D-1 demonstrates the pattern. Future codification slices (especially those touching multi-file slice artefacts) should run the to-be-codified discipline on their own draft as the FIRST prerequisite-check step. The discipline is most likely to catch its own author.
- **`grep -r` sibling-site verification belongs in every ACCEPTED-FIXED disposition** — slice-022 M-add-2 + M-add-3 + must-not-defer count sweep collectively demonstrate the Wiegers coverage-symmetry class. Worth codifying as Dim 9 sub-clause at /critic-calibrate slice-023 codification. Format: "After applying fix at site X, the Builder MUST run `grep -r '<canonical phrase>'` across mission-brief + design + ADR + milestone + changelog-target and propagate."
- **ADR partial-supersession encoding works** — single `supersedes: <prior>` frontmatter slot + body-level scope enumeration is sufficient for partial supersession. Future ADRs that partially supersede prior ADRs should use this pattern. Critical detail: do NOT add a `superseded-by:` field to the prior ADR (violates append-only and isn't supported by ADR family convention).
- **CRLF/LF environmental drift may be systemic** — slice-022 caught one instance unrelated to slice scope. Worth a recon spike to scan all installed-copy skill files at slice-023+ entry. If pattern recurs, codify `tools/line_ending_audit.py`.
- **Two-pass detection for destructive predicates** — `git cherry` Pass 1 + aggregate-tree-diff Pass 2 fallback is the right shape for any commit-reachability check that gates destructive action. Pattern is portable to future git-state-detection scenarios.
