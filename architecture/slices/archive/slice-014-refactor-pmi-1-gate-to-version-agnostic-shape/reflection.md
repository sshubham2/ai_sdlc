## Discovered

- **NEW Dim 9 sub-class candidate at N=1**: **`pytest-namespace-package-import-mode-defeats-dotted-string-monkeypatch-target`**. When `tests/` is a namespace package (no `__init__.py`) while `tests/methodology/__init__.py` exists, pytest's default import-mode places the running test module under `methodology.test_methodology_changelog` (bare key) in sys.modules — NOT under the fully-qualified `tests.methodology.test_methodology_changelog` dotted path. Any code using dotted-string module-target patterns (`monkeypatch.setattr("dotted.path.attr", val)`, `importlib.import_module("dotted.path")`) imports a separate copy under the dotted key, leaving the running test's namespace untouched. Same root-cause family as VAL-1 Layer B `tests` namespace-package class (N=11 → **N=12 cumulative recurrence** at slice-014). Promote to Dim 9 sub-class refinement at N=2 if recurs at slice-015+. Joins the watch-list for /critic-calibrate next-trigger.
